## Q2. What is the critical path, how many cells are on it, and how does it compare with about 2N full-adder delays?
OpenSTA (typical corner, tt_025C_1v80) gives a worst slack of 7.21 ns at T = 10 ns, so Tmin = 10 - 7.21 = 2.79 ns and Fmax = 1000 / 2.79 = 358.4 MHz; the rerun at T = 2.79 ns has +0.003 ns slack. The critical path starts at the input register for a[1] (`_91_`, a_r[1]) and ends at the output register for p[6] (`_88_`), so it is register to register, as expected with registered inputs and outputs. It has 9 cells: the launching dfrtp_1 and 8 logic cells (clkinv, o311ai, a21oi, maj3, xnor3, maj3, maj3, xor3), plus the capturing flip-flop. Only 5 of the 8 logic cells are full-adder functions (3 maj3 carries, 1 xnor3 sum, 1 xor3 sum), against the estimate of about 2N = 8 full-adder delays. The path is shorter than the estimate because ABC maps a whole full-adder carry into one maj3 cell and a whole sum into one xor3/xnor3 cell, and because the constant-zero carry-ins of each row and the zero top bit of row 0 turn the first adders into simpler gates, which ABC merged with the AND gates into compound cells (o311ai, a21oi). Of the 2.79 ns, 2.254 ns is logic delay and 0.533 ns is flip-flop clock-to-Q (0.398) plus setup (0.135).

## Q6. How would the number of full adders and the critical path delay change for an 8-bit multiplier?
From Section 2, an N-bit array multiplier needs N^2 AND gates and N(N-1) full adders, and its longest path is about 2N full-adder delays. For N = 4: 16 AND gates, 4 x 3 = 12 full adders, about 8 full-adder delays. For N = 8: 64 AND gates, 8 x 7 = 56 full adders, about 16 full-adder delays. So the adder count grows by 56 / 12 = 4.7 times (it grows as N^2), while the critical path only doubles (it grows linearly with N). Using our own numbers: the logic part of our critical path is 2.254 ns, so doubling it gives about 4.51 ns; adding the same flip-flop overhead of 0.533 ns gives Tmin of about 5.04 ns, so Fmax would fall from 358.4 MHz to about 1000 / 5.04 = 198 MHz. This is a first-order estimate; the real value depends on how synthesis maps the larger array.
